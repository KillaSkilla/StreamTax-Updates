# StreamTax – Update-Kanal

Dieses Repository dient ausschließlich der Verteilung freigegebener StreamTax-Windows-Updates. Der Quellcode bleibt privat.

## Veröffentlichungen

[Releases](https://github.com/KillaSkilla/StreamTax-Updates/releases) enthalten den Installer, seine Tauri-Update-Signatur und die Versionsdatei `latest.json`. Der Launcher prüft die Signatur vor einer Installation.

Aktuell wird der Update-Kanal eingerichtet. Solange keine signierte Veröffentlichung vorhanden ist, stehen hier keine automatischen Updates zur Verfügung.

**Entwickler-Testphase:** Keine echten Steuerdaten verwenden. Tauri-Update-Signaturen sind keine Windows-Authenticode-Signaturen.

Bitte keine persönlichen Daten, Belege, Backups, Zugangsdaten oder Schlüssel in diesem öffentlichen Repository veröffentlichen.
